AtendeAI

Aplicação em desenvolvimento voltada à análise de atendimentos utilizando inteligência artificial generativa. O sistema integra uma API de LLM para analisar conversas e retornar informações estruturadas para apoiar a organização dos atendimentos.

O que pratiquei
  • Integração com API do Gemini
  • Envio e processamento de dados de conversas
  • Respostas estruturadas em JSON
  • Classificação por resumo, categoria e prioridade
  • Integração entre aplicação, banco de dados e LLM
