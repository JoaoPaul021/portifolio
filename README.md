# Portfólio geral — João Paulo Gutierres Dornelas

Esta versão foi criada para funcionar como um portfólio profissional geral, sem ficar direcionada a uma vaga específica.

## Conteúdo incluído
- Formação em Tecnologia em Sistemas para Internet (IFSP)
- AtendeAI
- TCC: Análise de Dados para Personalização de Conteúdos em Aplicações Web
- Estudos práticos em Lua 5.4
- JavaScript, HTML5, CSS, Python, Java, MySQL, SQL e APIs
- Experiência profissional administrativa com destaque para competências transferíveis

## Como visualizar
Abra `index.html` no navegador.

## Como publicar
O site é estático e pode ser publicado gratuitamente em:
- GitHub Pages
- Netlify
- Vercel
